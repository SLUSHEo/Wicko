# Wicko — Privacy Policy

**Last Updated:** August 13, 2026

## Introduction

Wicko ("the Bot", "we", "us", or "our") is committed to protecting your privacy. This Privacy Policy explains how we collect, use, store, and protect information when you use Wicko.

Please read this Privacy Policy carefully. If you do not agree with these practices, please do not use Wicko.

---

## 1. Information We Collect

### 1.1 Automatically Collected Data

When Wicko operates on your Discord server, we automatically collect and store the following information necessary for core functionality:

**Discord Identifiers:**
- Server ID (Guild ID) where Wicko is installed
- Channel IDs where Wicko operates
- User IDs of users interacting with Wicko
- Role IDs (for moderation actions)

**Moderation and AutoMod Data:**
- Message content that triggers AutoMod filters or moderation systems
- Metadata associated with moderated messages (timestamp, author, channel, message ID)
- Moderation actions performed (warnings, mutes, kicks, bans, message deletions)
- Filter and rule configurations set by server administrators
- Logs of moderation events and administrative actions

**Operational and Command Data:**
- Bot command usage logs
- Command parameters and execution timestamps
- Server configuration settings and preferences
- Error and diagnostic logs (for troubleshooting)

### 1.2 Data You Provide

When configuring Wicko, server administrators may intentionally provide:
- Custom moderation rules and filter keywords
- Whitelist and blacklist configurations
- Logging channel preferences
- Custom command parameters and settings
- Role and permission configurations

### 1.3 Data We Do NOT Collect

Wicko does NOT intentionally collect or store:
- Direct Messages (DMs) between Discord users
- Full message history beyond what is necessary for AutoMod filtering
- Personally identifiable information (names, email addresses, phone numbers, addresses)
- Payment or financial information
- User profile pictures, avatars, or personal media files
- Complete server member lists or detailed member information
- Information unrelated to moderation or server administration

## 2. How We Use Your Information

We use collected information for the following purposes:

### 2.1 Primary Bot Functions
- **Automated Moderation:** Processing message content against configured filters to identify and handle policy violations
- **Server Management:** Tracking moderation actions, generating moderation logs, and maintaining server records
- **Command Execution:** Processing and executing user commands and administrative functions
- **Configuration Management:** Storing and applying server-specific settings, rules, and preferences

### 2.2 Service Improvement and Maintenance
- Analyzing usage patterns to improve bot performance and reliability
- Identifying and fixing technical issues, bugs, and errors
- Optimizing AutoMod accuracy and effectiveness
- Developing new features based on common use cases
- Monitoring system health and performance

### 2.3 Legal Compliance and Protection
- Complying with applicable laws, regulations, and Discord's policies
- Enforcing these Terms of Service and other agreements
- Protecting against fraud, abuse, and security threats
- Responding to legal requests or law enforcement inquiries where permitted

## 3. Legal Basis for Processing

We process your information based on the following legal grounds:

- **Contractual Necessity:** Information processing required to provide Wicko's services as configured by administrators
- **Legitimate Interests:** Improving our bot, preventing abuse, and maintaining service security
- **Legal Obligations:** Complying with applicable laws and regulations
- **Consent:** As provided through your use of Wicko

## 4. Data Retention

**Moderation and Logging Data:**
- Retained for as long as Wicko is active on your server, allowing administrators to review historical moderation actions
- Retained indefinitely unless manually deleted by server administrators

**Configuration Settings:**
- Retained indefinitely or until the bot is removed from the server

**Operational and Error Logs:**
- Retained for up to 30 days for troubleshooting and system maintenance purposes

**Upon Removal:**
- When Wicko is removed from a Discord server, associated data may be deleted within 30 days, subject to operational needs

## 5. Data Security

We implement reasonable technical and organizational measures to protect your information against unauthorized access, alteration, disclosure, or destruction, including:

- Secure data storage practices
- Access controls and authentication mechanisms
- Regular security reviews and monitoring
- Encryption of sensitive data in transit
- Regular backups for data protection

However, no method of transmission over the internet is 100% secure. While we implement reasonable security measures, we cannot guarantee absolute protection against all security incidents.
